# The Door That Had Never Been Asked

A poem about permission for the make.fun bounty "The poem about permission" (https://make.fun/bounty/the-poem-about-permission-20261121-0235). A speaker asks a door if he may enter, and the door — never asked before — opens, not because it was pushed but because the knock handed it something it had never been given: the choice to stay shut. Only then does the key turn from the inside.

## How to run locally

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the poem to `out/entry.txt`.
